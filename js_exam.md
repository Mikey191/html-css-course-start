## 🟩 Первый этап

### Задача: Получение пользователей с [https://randomuser.me/api/](https://randomuser.me/api/)

#### Условие

Используя JavaScript, нужно отправить запрос на сервер [https://randomuser.me/api/?results=10](https://randomuser.me/api/?results=10) для получения массива пользователей (можно получать как **10**, так и **20**, **30**, **40** и более пользователей с помощью параметра `?results=20` или `?results=50`) и вывести каждого из пользователей в отдельную строку.

Для каждого пользователя нужно вывести:

- Картинку `picture.thumbnail`
- Имя (`name.first` + `name.last`)
- Электронную почту (`email`)
- Телефон (`phone`)
- Пол (`gender`)

#### Дополнительно:

- Для создания элементов используйте метод `createElement()` и `appendChild()`.
- Допускается использовать `innerHTML` для упрощения, но предпочтительнее создавать DOM-элементы вручную.
- Стилизовать пользователей так, чтобы **каждый пользователь** занимал одну строку (`display: flex`) и все его данные были видны в удобной верстке.

---

### ✅ Алгоритм для выполнения

1. Создайте HTML-файл.
2. Добавьте в `body` блок-контейнер для пользователей (например, `div id="userList"`).
3. С помощью `fetch()` отправьте GET-запрос:

   ```
   https://randomuser.me/api/?results=10
   ```

4. Полученный результат преобразуйте в JSON (`response.json()`).
5. Для каждого элемента массива пользователей:

   - Сформируйте DOM-структуру строки.
   - Вытащите из объекта:

     - Картинку `user.picture.thumbnail`
     - Имя `user.name.first + user.name.last`
     - Электронную почту `user.email`
     - Телефон `user.phone`
     - Пол `user.gender`

   - Добавьте собранный ряд в контейнер.

6. Отстилизовать каждую строку:

   - `display: flex`
   - Отступы между элементами
   - Отдельный блок для картинки
   - Выравнивание элементов

## 🟩 Второй этап: поиск пользователей:

#### Условие

- На странице, где уже реализован список пользователей, нужно добавить поле поиска.
- Поле поиска позволяет искать пользователей:

  - По имени
  - По номеру телефона
  - По email

- При вводе текста в поле — отображаются только те пользователи, у которых введённый текст встречается в имени, телефоне или email.

#### Дополнительно:

- Поиск регистронезависимый (например, поиск `john` должен найти `John`).
- Для реализации использовать метод `filter()` массива пользователей.
- Отфильтрованный результат отображать в ранее созданный блок пользователей.

---

### ✅ Алгоритм для выполнения

1. Над блоком пользователей добавить элемент `<input>` для поиска.
2. При каждом изменении текста в поле искать пользователей:

   - Проверить, содержится ли введенный текст в `name.first + name.last`, `email` или `phone`.

3. Отфильтрованных пользователей вывести в блок.
4. Если нет результатов — вывести сообщение: `Пользователи не найдены`.

## 🟩 Третий этап: сортировка пользователей:

#### Условие

- На странице отображается список пользователей.
- Над этим списком есть **заголовок таблицы** с именами столбцов:

  - Фото (можно оставить пустым)
  - Имя
  - Email
  - Телефон
  - Пол

- При клике на заголовок столбца `Имя` происходит сортировка пользователей **по имени** (сначала A–Я, при повторном клике Я–A).
- При клике на заголовок столбца `Пол` происходит сортировка пользователей **по полу** (male / female).

#### Дополнительно:

- Сортировка идёт прямо в массиве данных.
- При каждом клике список пользователей перерисовывается.

---

### ✅ Алгоритм для выполнения

1. Сверстать шапку для таблицы пользователей.
2. При клике на `Имя` — сортировать массив пользователей:

   - Сначала в алфавитном порядке (A–Я).
   - При повтором клике — в обратном (Я–A).

3. При клике на `Пол` — сортировать пользователей:

   - Сначала `female` → `male`.
   - При повтором клике — наоборот.

4. Отрендерить пользователей в блоке.
5. Сохранять состояние сортировки для переключения направления.

## 🟩 Четвёртый этап: пагинация.

#### Условие

- Загрузить пользователей с [https://randomuser.me/api/?results=40](https://randomuser.me/api/?results=40).
- Отобразить пользователей **по 10 человек на странице**.
- Сформировать внизу блок с номерами страниц для переключения (`1, 2, 3, 4`).
- При клике на номер страницы — отображать соответствующих пользователей.
- Выводится только 10 пользователей за раз.

---

### ✅ Алгоритм для выполнения

1. Сформировать HTML-каркас:

   - Секция для пользователей (`div id="userList"`).
   - Секция для пагинации (`div id="pagination"`).

2. Загружать пользователей из API (40 пользователей).
3. Сохранять их в массив (`allUsers`).
4. Отрендерить первых 10 пользователей.
5. Сформировать внизу блок для пагинации:

   - Сосчитать количество страниц (`allUsers.length / 10`).
   - Для каждой страницы сделать кнопку.
   - При клике — отображать пользователей для этой страницы.

## 🟩 Пятый этап: использование cookie для авторизации.

#### Условие

- Создать **JSON-файл** `users.json` (в корне), в котором хранится список пользователей для проверки логина:

```json
[
  { "login": "user1", "password": "pass1" },
  { "login": "user2", "password": "pass2" },
  { "login": "user3", "password": "pass3" },
  { "login": "user4", "password": "pass4" },
  { "login": "user5", "password": "pass5" }
]
```

#### Требования:

- На странице проверять **cookie**:

  - Если в **cookie** есть ключ `username` — вывести пользователей.
  - Если нет — вывести форму для ввода логина и пароля.

- При введении логина и пароля:

  - Сверить введенные данные со списком пользователей из `users.json`.
  - При успешной проверке установить cookie `username`.

- При успешной авторизации — вывести пользователей.
- Дополнительно добавить в начале страницы приветствие в формате:

  ```
  Здравствуйте, <username>!
  ```

---

### ✅ Алгоритм для выполнения

1. При загрузке страницы:

   - Проверить cookie `username`.
   - Если есть — вывести пользователей.
   - Если нет — вывести форму для логина.

2. При отправке формы:

   - Загрузить `users.json`.
   - Сверить введенный логин и пароль.
   - При успешной авторизации — установить cookie и перезагрузить страницу.

3. Отрендерить пользователей из [https://randomuser.me/api/](https://randomuser.me/api/).
